# Dialogue UI — Sirus 3.3.5a

**Dialogue UI** заменяет стандартные окна разговора с NPC и заданий на кинематографичный диалог: текст NPC, варианты ответа и награды показываются в одном аккуратном окне, а камера плавно наводится на собеседника.

> [!IMPORTANT]
>
> ### Только Sirus + 3.3.5a
>
> Эта версия предназначена **ИСКЛЮЧИТЕЛЬНО для клиента Sirus 3.3.5a** с интерфейсом **DF UI** (патч `patch-ruRU-i`, `Interface` **30300**).
>
> Розничный клиент (Retail), Classic всех версий, WoW: Forever и другие приватные серверы **не поддерживаются**.
>
> Обычный клиент Sirus **без DF UI** не проверялся и отдельно не поддерживается.

### Установка

Скачайте архив `DialogueUI-<версия>-sirus.zip` со страницы [Releases](https://github.com/AmonRay/YUI-Dialogue-Sirus/releases), распакуйте папку `DialogueUI` в `Interface/AddOns/` клиента Sirus и перезагрузите интерфейс командой `/reload`.

Папка должна называться ровно `DialogueUI` — иначе клиент 3.3.5a не увидит аддон, а пути к текстурам и шрифтам внутри аддона перестанут работать. Если клонируете репозиторий, соберите готовую папку скриптом `_Dev/build_335.ps1`.

### Возможности

- **Диалог вместо окон.** Разговор с NPC, взятие и сдача заданий проходят в одном окне без стандартных GossipFrame и QuestFrame.
- **Управление с клавиатуры.** Варианты ответа выбираются цифрами, принять задание или продолжить разговор можно без мыши.
- **Награды на виду.** Предметы, деньги и опыт за задание показываются сразу, с подсказками по наведению.
- **Книги и письма.** Отдельное окно для чтения книг, табличек и писем.
- **Камера.** Плавное приближение к собеседнику на время разговора (можно отключить).
- **Темы и шрифты.** Светлая и тёмная тема, настраиваемый размер текста.

### Совместимость

| Клиент | Статус |
| --- | --- |
| Sirus 3.3.5a + DF UI (`Interface` 30300) | Поддерживается |
| Sirus 3.3.5a без DF UI | Не проверялся |
| Retail, Classic, WoW: Forever, другие приватные серверы | Не поддерживается |

Если что-то сломалось, включите вывод ошибок командой `/console scriptErrors 1`, сделайте `/reload` и приложите текст первой ошибки к [issue](https://github.com/AmonRay/YUI-Dialogue-Sirus/issues).
