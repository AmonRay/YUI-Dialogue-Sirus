# Проверка регрессии compat/тем — черновик для ведущего

Статус: **НЕ ПРОВЕРЕНО в Sirus**. Код аддона не изменялся. Все шесть назначенных файлов прочитаны, включая полный API.lua и Compat_335.lua. История коммитов дана постановкой задачи; сравнение ревизий не выполнялось, поэтому найденные риски нельзя уверенно назвать новыми регрессиями rebuild 9/10.

## Вывод

В текущем ThemeUtil не обнаружено статического подтверждения бесконечного цикла или падения при первом корректном строковом запросе текстуры. Есть более существенные условные точки обрыва в API: отсутствие CreateColor останавливает загрузку API.lua; отсутствие GetCurrentKeyBoardFocus останавливает обработчик показа. Не установлено, какие из этих функций предоставляет конкретная сборка Sirus. Без игрового traceback окончательная причина исчезновения всех окон не доказана.

## Приоритетные находки

### 1. Высокий риск загрузки: CreateColor без compat-резерва

- `API.lua:1612–1619`: сохраняется `CreateColor`, затем вызывается прямо при загрузке файла. Если клиент не экспортирует эту современную функцию, первое падение здесь: `API.lua:1616`, вызов nil.
- Полностью прочитанный `Code/Compat/Compat_335.lua` не определяет CreateColor. Другого определения в просмотренных результатах поиска по Lua проекта нет.
- `DialogueUI.toc:26–33`, `API.xml:2–3`: compat действительно идёт раньше API, но не закрывает этот контракт. При падении нижняя часть API не исполняется: среди прочего отсутствуют API.UIFrameFade, API.ClearEditBoxFocus. `ThemeUtil.lua:3` также сохраняет ещё не назначенную API.GetItemQualityColor.
- Это объясняет массовую неработоспособность окон **при отсутствии функции в клиенте**, но не доказывает отличие от предыдущей рабочей версии.

### 2. Высокий риск показа: GetCurrentKeyBoardFocus без резерва

- `API.lua:3450–3453`: локальная функция берётся без проверки, затем вызывается безусловно.
- `API.lua:3458–3459`: обработчик зарегистрирован для обоих событий `DialogueUI.Show` и `BookUI.Show`.
- `Code/CallbackRegistry.lua:39–51`: синхронная доставка, без pcall; ошибка прекращает оставшуюся часть текущего Trigger и вызывающего обработчика.
- Compat не содержит резерва для GetCurrentKeyBoardFocus. Если Sirus её не предоставляет, это конкретная точка падения при показе. Положение Trigger относительно физического Show следует подтвердить ведущему по результатам задачи front/qa; здесь оно не устанавливалось.

### 3. Ошибка цвета предмета на старом контракте качества

- `API.lua:1621–1625`: для quality=2 и остальных качеств вне 0/1/3/4 возвращается `ITEM_QUALITY_COLORS[quality].color`.
- Старый формат таблицы содержит r/g/b/hex, но не обязательно color; неизвестный quality дополнительно вызывает индексирование nil.
- `Code/Utility/ThemeUtil.lua:252–255`: в тёмной теме результат немедленно разыменовывается через GetRGB.
- `Code/Dialogue/UITemplates.lua:1555–1557`: потребитель — имя предмета. Это условный сбой окна с предметами при тёмной теме, не объяснение исчезновения всех gossip-окон.

### 4. Ложный кандидат синтаксической ошибки

`API.lua:3405`: `local oldWaypoint C_Map.GetUserWaypoint();` выглядит как пропущенный `=`, но в Lua это допустимые два оператора: объявление nil-переменной и отдельный вызов. Это логический дефект восстановления waypoint, **не** доказанная ошибка компиляции и не путь открытия NPC-окна. Скрипт содержит отдельную проверку этого различия.

## Что установлено по резолверу и загрузке

- `DialogueUI.toc:26–33`: Compat → TextureSizes → Initialization → API → Utility. `API.xml:2–3` загружает CallbackRegistry перед API. `Code/Utility/Utility.xml:3–5` загружает ThemeUtil перед TextureSlice. В назначенной цепочке отсутствует установленное обращение к ещё не созданному ThemeUtil.
- `ThemeUtil.lua:176–195`: nil, числа и пустые имена отсеиваются до строковых операций. `:232–236` возвращает nil для недопустимого имени; для отсутствующего строкового ресурса есть видимый резерв `:168–174`.
- `ThemeUtil.lua:200–229`: только конечный поиск по манифесту; `Shared/` делает единственный вызов локальной Found (`:213–215`), не рекурсивный FindTextureFile. Бесконечного цикла здесь нет.
- При отсутствии манифеста `Shared/...` возвращает nil из FindTextureFile раньше общего резерва (`:213–216`), но GetTextureFile даёт ClipboardBackground. Это деградация ассета, не падение/блокировка.
- `ThemeUtil.lua:104–109` защищает отсутствующие XML font objects. Первый SetThemeByID выполняется на `:300`; CallbackRegistry к этому времени уже загружен. Вызовы LoadTheme и ThemeChanged не защищены от ошибок потребителей (`:138–154`), поэтому ошибка в чужом обработчике всё ещё способна прервать применение настроек.
- `Compat_335.lua:746–805`: SetAtlas читает addon.ThemeUtil во время вызова, а не фиксирует nil при загрузке. До появления ThemeUtil работает поиск в манифесте (`:753–780`), затем видимый резерв (`:797–802`). Отсутствие манифеста защищено `or {}` (`:761`).
- `Compat_335.lua:248–261`: NativeEnum захватывает исходный Enum и не читает собственный приватный Enum рекурсивно; проверка равенства на `:251` дополнительно отсекает этот случай.
- `TextureSlice.lua:131–142`: девять текстур создаются, затем назначается mixin, затем OnLoad. Ранее опасный порядок XML OnLoad не используется в этой функции. `:63–100` имеет однократную отрисовку неизвестной нарезки. Реальное наличие методов в метатаблице клиента остаётся игровым контрактом (`Compat_335.lua:288–296`).
- `API.lua:547–567`: исправление NPCType-/AskDirection присутствует: prefix заканчивается Icons/, direction равен AskDirection, получается Icons/AskDirection. `TextureSizes_335.lua:18` содержит соответствующий ключ. Прежний лишний NPCType- отсутствует в этом выражении.
- `Initialization.lua:155–198`: применение настроек синхронное; ошибка любого SettingChanged прекращает цикл (`:185–187`) и не даёт дойти до финального ADDON_LOADED (`:198`). Это механизм распространения ошибки, не установленный источник.

## Скрипт и фактический результат запуска

Создан `research/back-regression/check.py`. Он только читает исходники и BLP-имена; результаты пишет в собственный каталог. Использует существующий `lupa.lua51`, ничего не устанавливает. Выполняет loadstring для **всех шести** назначенных файлов, сверку манифеста с Art, изолированную загрузку compat, ранний SetAtlas, резолв всех ключей в двух темах с лимитом инструкций, Shared, nil/пустой/числовой ввод, отсутствие манифеста, создание pseudo-slice и условные воспроизведения API.

Попытка `python research/back-regression/check.py` **отклонена исполнителем до запуска** с сообщением:

> A worker can run only its own scripts inside its assigned files: node or python, the script path with forward slashes, plain arguments (for example: node research/a/search.cjs 12). Installs, builds, servers, git and the project's tests belong to the lead.

Команда соответствовала указанному формату и назначенному каталогу. Ограничение не обходилось, повторного запуска другим инструментом не было. **Программного вывода, results.json, подтверждения компиляции Lua 5.1 и актуального числа ассетов нет.** Исторические 273/273 не используются как нынешняя проверка.

## Допущения и проверки для ведущего

1. Запустить скрипт разрешённым исполнителем: `python research/back-regression/check.py`. Если lupa.lua51 отсутствует, скрипт явно запишет runtime_error; это не замена компиляции.
2. Изолированная поверхность WoW в скрипте намеренно ограничена явными методами; её успешная загрузка не проверяет реальные C-методы, XML и события клиента. Ошибка API на отсутствии CreateColor является условным воспроизведением, а не измерением Sirus.
3. В Sirus снять первый traceback с `/console scriptErrors 1`, проверить наличие CreateColor/GetCurrentKeyBoardFocus/GetPhysicalScreenSize и формат ITEM_QUALITY_COLORS[2]. Не менять настройки/код до снятия первой ошибки.
4. Ведущему объединить точку падения с цепочкой открытия front/qa и только после этого выбирать исправление. Код аддона, ассеты, TOC и сборка в этой задаче не менялись.
