# Регрессия создания/показа окна: фронт

**Непроверенный черновик для ведущего инженера.** Код аддона не изменён. Подтверждённая первопричина по назначенной зоне не установлена; найдено несколько точек, где ошибка подготовки окна прерывает показ. Ни одна из них без журнала ошибок клиента не является доказанным объяснением новой регрессии.

## Ограничение запуска и истории

Попытка `python research/front-regression/analyze.py` из корня проекта отклонена исполнителем до запуска. Получено: `A worker can run only its own scripts inside its assigned files: node or python, the script path with forward slashes, plain arguments ...` При этом скрипт находится именно в назначенном каталоге. Повторного обходного запуска не делал. **Программных чисел и результатов нет**, `analysis.json` и `recent.diff` не созданы.

Написанный анализатор готов для запуска ведущим: стандартная библиотека Python; читает исходники и Git-объекты, пишет только рядом с собой. Поддерживает loose/packed Git objects и delta, извлекает diff коммитов `039bb74` и `15e8f6c` относительно родителей без вызова git; проверяет XML, существование литеральных DUI-шаблонов, определения XML-mixin и цепочки `Schematic`; инвентаризирует return/pcall/современные методы/SetTexCoord. Сам анализатор пока не исполнен, его результаты нельзя считать проверенными. Сравнение реальных diff последних коммитов осталось незавершённым; подписи rebuild в TOC не заменяют diff.

## 1. Ошибка до Show оставляет всё окно скрытым — подтверждённая структура, не установленная причина

- `Code/Dialogue/DialogueUI.xml:364`: `DUIQuestFrame` создаётся `hidden="true"`.
- `Code/Dialogue/DialogueUI.xml:567`: корневой OnLoad вызывает mixin и `self:OnLoad()` без защиты.
- `Code/Dialogue/DialogueUI.lua:289–290`: `MainFrame` и `addon.DialogueUI` назначаются **в начале**, а не после успешного OnLoad.
- `Code/Dialogue/DialogueUI.lua:509`: `UpdateFrameSize()` вызывается до окончания OnLoad; `:517–520` — флаг загрузки и регистрация завершающих событий ещё позже.
- `Code/Dialogue/DialogueUI.lua:2406`: `HandleGossip` вызывается синхронно; `:2416–2419` — внешние колбэки, камера и анимация; только `:2422` выполняет `self:Show()`.

Следствие: существующий `addon.DialogueUI` ещё не доказывает успешную инициализацию. Ошибка создания кнопки, расчёта размеров, резолвера или callback прерывает текущую функцию до Show. В прочитанных назначенных файлах pcall-обёртки показа не обнаружены; ошибку следует искать в клиентском обработчике ошибок, а не считать её «успешно проглоченной» этим UI-кодом.

## 2. Первое окно обязательно запрашивает текстуры ещё до взаимодействия

- `Code/Dialogue/DialogueUI.lua:3454`: текстура `ScreenVignette` разрешается при выполнении файла, до создания XML-корня и до регистрации настроечных колбэков ниже `:3512`.
- `Code/Dialogue/DialogueUI.lua:309`: в корневом OnLoad создаётся `DUIDialogHotkeyTemplate`.
- `Code/Dialogue/DialogueUI.xml:50` → `Code/Dialogue/UITemplates.lua:1025–1026` → `:1044–1046`: создание hotkey немедленно вызывает `ThemeUtil:GetTextureFile("HotkeyBackground")`.
- `Code/Dialogue/DialogueUI.xml:561` → `Code/Dialogue/UITemplates.lua:2198–2199`, `:2227–2234`: дочерний InputBox также запрашивает `InputBox-SingleLine` при загрузке, даже если скрыт.

Это наиболее релевантные фронтовые точки для проверки гипотезы новой ошибки резолвера. Ошибка Lua внутри `GetTextureFile` здесь может остановить загрузку/OnLoad; просто отсутствующая картинка без Lua-ошибки обычно не объясняет исчезновение текста и всего окна. Саму реализацию резолвера исследует другая назначенная роль.

## 3. Обращения к nil в геометрии: опасный контракт есть, отсутствующее поле не доказано

- `Code/Dialogue/DialogueUI.lua:138–140`: `SetupObjectSize` проходит по `obj[k]` без проверки.
- `:148`, `:152`, вызов `:218–219`: затем вызывает методы найденного объекта при первом `UpdateFrameSize`.
- Указанные в `Schematic` `FrontFrame.Header.*`, `QuestPortrait.Model/Name`, `BackgroundFrame.ClipFrame.BackgroundDecor` визуально присутствуют в `DialogueUI.xml:367–529`.
- `Code/Dialogue/UITemplates.lua:1031` и `:1045`: hotkey обращается к `self.Background`; **поле не удалено** очисткой атласов, оно остаётся обычной `Texture` в `DialogueUI.xml:30–34`.
- `Code/Dialogue/QuestHeaderWidget.lua:41–42`: `f.Background:SetTexture/SetTexCoord`; поле сохраняется в `DialogueUI.xml:315–335`, конкретно `:319`.
- `Code/SharedUITemplates/GenericFrame.lua:69–75`: Background используется как Frame и на нём создаются девять текстур; это соответствует `SharedUITemplates.xml:8`, где Background действительно Frame, а не Texture.

То есть видимые кандидаты «SetTexCoord на удалённом Background» и «девять текстур создаются на Texture» текущими файлами **не подтверждаются**. Анализатор добавляет проверку всех цепочек Schematic, но её запуск ещё нужен.

## 4. Ранние return, реально способные отменить открытие

- `Code/Dialogue/DialogueUI.lua:2380–2390`: первоначальная загрузка откладывает событие. В `:2384` уже имеется страховка `IsLoggedIn()` с отсутствующим/устаревшим `worldEnteredTime`; потому старое объяснение «навсегда ждёт LOADING_SCREEN_DISABLED» текущим файлом само по себе не подтверждается. `PLAYER_ENTERING_WORLD` регистрируется в `:520`, обрабатывается в `:2686–2693`.
- `:2393–2397`: cutscene закрывает взаимодействие и возвращается до Show.
- `:2409–2412`: ложный результат обработчика отменяет Show.
- `:1243–1251`: `IsGossipHandledExternally()` сознательно отдаёт диалог внешнему обработчику.
- `:1281–1282`: авто-выбор сознательно отменяет текущий показ; `:1424–1426` аналогично для авто-завершения квеста.
- `:1269–1277`: ветвь NameplateGossip с return находится внутри многострочного комментария, **не считать её действующим блокером**.

Эти ветви не являются доказанной новой ошибкой шаблонов. Для общего отказа у всех НПЦ нужно подтвердить общую настройку/ошибочный результат функции либо исключение до Show; одиночный авто-выбор объясняет только соответствующие диалоги.

## 5. Современные методы: условные риски, у которых есть compat-покрытие

- `Code/Dialogue/UITemplates.lua:247`: `SetHyperlinksEnabled` при создании каждой option-кнопки. Compat задаёт noop в `Code/Compat/Compat_335.lua:317`.
- `Code/Dialogue/UITemplates.lua:2462–2475`, `:2492–2504`: XML-портрет при OnLoad использует `SetModelAlpha`, `OnModelLoaded`, табличный `SetLight`. Наличие адаптации `SetModelAlpha` и `WrapSetLight` видно в `Code/Compat/Compat_335.lua:374`, `:396–424`; объявлять эти методы корнем новой регрессии без ошибки клиента нельзя.
- `Code/Widget/WidgetManager.lua:378–380`: `CreateMaskTexture` и `AddMaskTexture`; CreateMaskTexture компенсируется compat (`Code/Compat/Compat_335.lua:332–335`). Этот код находится внутри `CreateAutoCloseButton`, а не в безусловной загрузке WidgetManager. Прямого вызова из корневого OnLoad диалога в прочитанном участке нет.
- `Code/SharedUITemplates/SharedUITemplates.lua:13–14`: `DUI_SetSharedTexture` не проверяет texture на nil, однако вызова этой функции в прочитанном SharedUITemplates.xml нет. Само определение не создаёт ошибки.

## Допущения и передача

Читается рабочая копия проекта, не установленная копия Sirus; совпадение версий не проверено. Часть крупных файлов просмотрена целевыми диапазонами и поиском, а не исполнена целиком. Статический анализ не моделирует XML-движок 3.3.5, метатаблицы виджетов и ошибки реального клиента. Определения XML-шаблонов в скрипте проверяются по всему исходному дереву; это проверка наличия, а не доказательство корректного порядка загрузки.
