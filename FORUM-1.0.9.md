# Dialogue UI 1.0.9 — для публикации на форуме

**Dialogue UI 1.0.9 для Sirus 3.3.5a — окно настроек и награды**

Обновление аддона, который заменяет стандартные окна разговора и заданий одним
кинематографичным диалогом.

**Что исправлено в 1.0.9**

- **Окно настроек, вкладки.** Названия вкладок больше не накладываются друг на друга —
  ширина кнопок считается по реальной ширине текста.
- **Окно настроек, прокрутка.** Список пунктов прокручивается колесом мыши в любом месте
  окна, все пункты доступны до конца списка.
- **Окно настроек, правая часть.** При наведении на пункт снова показывается его описание,
  а для пунктов с оформлением — превью темы. Раньше этот текст уходил под фон окна.
- **Окно настроек, шрифт.** В поле «Шрифт» отображается текущий выбранный шрифт.
- **Окно задания, награды.** Иконка предмета больше не перекрывается световой текстурой —
  она оставалась на месте после анимации выбора награды.
- **Окно задания, подсказки.** При наведении на награду (предмет, деньги, опыт, валюта)
  снова появляется подсказка.
- **Подсказки.** Строка «Нажмите … для открытия настроек» показывает клавишу
  (например, «Нажмите [F1] для открытия настроек») вместо пустого места.

**Установка**

1. Скачайте `DialogueUI-1.0.9-sirus.zip` из релиза на GitHub.
2. Распакуйте папку `DialogueUI` в `Interface/AddOns/` клиента Sirus 3.3.5a.
3. В игре выполните `/reload`.

Папка должна называться ровно `DialogueUI` — иначе клиент 3.3.5a не увидит аддон.

**Если что-то не работает**

Включите вывод ошибок командой `/console scriptErrors 1`, сделайте `/reload`, повторите
действие и приложите текст первой ошибки к issue в репозитории — так проблема будет
видна сразу.
