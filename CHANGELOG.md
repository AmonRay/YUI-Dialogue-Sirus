# Changelog — Dialogue UI (Sirus 3.3.5a)

## 1.0.9

### Внутриигровой changelog

**Окно задания**

- Награды: иконка предмета больше не перекрывается текстурой выбора награды.
- Наведение на награду (предмет, деньги, опыт, валюта) снова показывает подсказку.
- Подсказка «Нажмите … для открытия настроек» показывает клавишу (например, `[F1]`) вместо пустого места.

**Окно настроек**

- Названия вкладок больше не наезжают друг на друга.
- Список пунктов прокручивается колесом мыши в любом месте окна — доступны все пункты до самого низа.
- Справа снова видны описание пункта и превью темы.
- В поле «Шрифт» показывается текущий выбранный шрифт.

### Текст для публикации на форуме

**Dialogue UI 1.0.9 — исправления окна настроек и окна задания**

Обновление для клиента Sirus 3.3.5a. Исправлено:

- **Окно настроек.** Названия вкладок больше не накладываются друг на друга: ширина кнопок считается по реальной ширине текста, а не по предварительной оценке.
- **Окно настроек.** Список пунктов прокручивается колесом мыши в любом месте окна, все пункты доступны до конца списка.
- **Окно настроек.** Справа снова показываются описание выбранного пункта и превью темы — текст больше не уходит под фон окна.
- **Окно настроек.** В выпадающем списке «Шрифт» отображается текущий выбранный шрифт.
- **Окно задания.** У наград иконка предмета больше не перекрывается световой текстурой, которая оставалась на месте после анимации.
- **Окно задания.** При наведении на награду (предмет, деньги, опыт, валюта) снова появляется подсказка.
- **Подсказки.** Строка «Нажмите … для открытия настроек» показывает клавишу (например, `[F1]`) вместо пустого места.

Установка: распакуйте папку `DialogueUI` из архива в `Interface/AddOns/` и выполните `/reload`. Папка должна называться ровно `DialogueUI`.

Если что-то сломалось, включите вывод ошибок командой `/console scriptErrors 1`, сделайте `/reload` и приложите текст первой ошибки к issue в репозитории.
